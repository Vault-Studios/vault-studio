# Content model

## Project

- slug, language, title, client, category, year
- summary, location, services, credits
- cover image with alt text and crop hotspot
- gallery items with image, alt text, caption and ordering
- video provider ID, poster, duration and fallback URL
- featured order, publish state and SEO title/description

Create one linked document per language. Do not store bookings, private emails or moderation records in the CMS.

## Site settings

- business identity and contact channels
- service descriptions
- social links and default SEO copy
- language navigation labels

Operational availability belongs in the database so it cannot become stale editorial copy.
