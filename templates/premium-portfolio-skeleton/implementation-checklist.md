# Implementation checklist

1. Establish brand, routes, languages and final content inventory.
2. Build the local content fallback before connecting the CMS.
3. Add CMS queries with caching, validation and graceful fallback.
4. Put bookings and reviews behind same-origin server endpoints.
5. Enable database validation, RLS, moderation states and spam controls.
6. Use adaptive video streaming with poster images and lazy loading.
7. Translate navigation, forms, metadata, errors and dynamic CMS entries.
8. Verify keyboard, touch, reduced-motion, low-bandwidth and mobile behavior.
9. Test empty, loading, success and failure states for every external service.
10. Document the editor workflow and back up configuration before launch.
